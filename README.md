## Week-1,2: Adding Functionality
In this part of the assignment, we use JavaScript to add interactivity to the page:
* A burger menu on both pages
* A popup for animal cards on both **main** and **pets** pages
* An infinite slider-carousel on the **main** page
* Pagination on the **pets** page

## Repository requirements:
### Task Instructions:
* The task is to be completed in your personal private repository.
* Create a new branch shelter from the main branch. Inside the shelter branch, create a folder named shelter and place the project files there.
* Use GitHub Pages (https://pages.github.com/) for deployment. If you are unable to use GitHub Pages, use Netlify Drop.
* Name the page using the following format: GitHub account name - task name.

**Since the task is divided into two parts, there will be two versions of the shelter project:**
1. The shelter branch will contain the first part of the task.
2. When starting the second part of the task, create a new branch called shelter-part2 from the shelter branch. This allows you to continue from where you left off in the first part.

**After completing the second part of the task:**
* Create a Pull Request from the shelter-part2 branch to the shelter branch.
* Check for conflicts and perform the Merge.

**Important Note:**
* The Pull Request and merge should only be done from the development branch to the initial branch of the task (i.e., shelter). Do not merge into the main branch!

### Project Structure
* The internal structure of the project is up to you. The simplest option is to have separate layouts for the pages, each with its own styles.

### Submission:
* When submitting the work, ensure that the provided link opens the main page of the deployed project.
* Send the link to your work and GitHub Pages to our group in Microsoft Teams before the deadline.
